⏺ Let me give you my analysis on Canvas 2D vs SVG for geometry rendering:

  Canvas 2D vs SVG Comparison

  | Aspect             | Canvas 2D                               | SVG
                                         |
  |--------------------|-----------------------------------------|----------
  ---------------------------------------|
  | Performance        | Excellent for >1000 objects, animations | Good for
  <500 objects, degrades with complexity |
  | Events             | Manual hit-testing required             | Native
  DOM events per element                   |
  | Accessibility      | None (opaque bitmap)                    | Screen
  reader support possible                  |
  | Styling            | Programmatic only                       | CSS
  classes, :hover, transitions                |
  | Export             | Needs svgcanvas.js shim                 | Native
  (it IS vector)                           |
  | Debugging          | Difficult (no inspection)               | DevTools
  element inspection                     |
  | Memory             | Lower per object                        | Higher
  (DOM nodes)                              |
  | Svelte integration | Canvas ref, imperative                  | Reactive
  bindings, each blocks                  |

  My Recommendation: SVG (with Canvas option for animations)

  Reasons for SVG in educational geometry:
  1. Accessibility - Important for education (screen readers, keyboard nav)
  2. Constructions are typically <200 objects - performance is fine
  3. Svelte synergy - Reactive updates, {#each} loops, transitions
  4. Native export - No svgcanvas.js hack needed
  5. CSS styling - Easy theming, dark mode, hover states
  6. Debugging - Inspect elements in DevTools

  Hybrid approach: Use SVG for geometry objects, Canvas overlay for:
  - Animation trails (locus)
  - Turtle graphics (many small segments)
  - Real-time previews during construction

     │ export class TimelineController {                                       │
     │   // State (Svelte 5 runes)                                             │

     │   let interactiveMode = $derived(timeline.isComplete &&                 │
     │ allowExploration);                                                      │

     │   />                                                                    │
     │                                                                         │

     │   {/if}                                                                 │
     │                                                                         │
