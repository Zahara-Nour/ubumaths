An increasing function preserves order: if ~a<b~, then ~f(a)<f(b)~. A decreasing function reverses it: if ~a<b~, then ~f(a)>f(b)~. So we compare the starting numbers, then use the direction of variation.

1. ~m=-3~ is negative: ~f~ is decreasing on $\mathbb{R}$, so it reverses order.
   a. ~1.4^2=1.96~ and ~1.96<2~, so $1.4<\sqrt{2}$. Since ~f~ is decreasing: $f(\sqrt{2})<f(1.4)$.
   b. ~\pi>3~, so ~-\pi< -3~. Since ~f~ is decreasing: ~f(-\pi)>f(-3)~.

2. ~g(x)=1/4x+1~: ~m=1/4~ is positive, so ~g~ is increasing on $\mathbb{R}$, it preserves order.

   ~0.001<0.01~, so ~g(0.001)<g(0.01)~.

3. The gradient of ~h~ is the rate of change between ~2~ and ~7~:

   $$\begin{align*}m&=\dfrac{h(7)-h(2)}{7-2}\\&=\dfrac{1-5}{5}\\&=-\dfrac{4}{5}\end{align*}$$

   ~m~ is negative: ~h~ is decreasing on $\mathbb{R}$.

   We could also see it without calculating: ~2<7~ and ~h(2)>h(7)~, so ~h~ is neither increasing nor constant; an affine function that is neither increasing nor constant is decreasing.
