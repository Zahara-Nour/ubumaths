Une fonction affine ~f(x)=mx+p~ est croissante sur $\mathbb{R}$ si ~m>0~, décroissante sur $\mathbb{R}$ si ~m<0~, et constante si ~m=0~ : le sens de variation se lit sur le signe du coefficient directeur.

1.
   a. ~m=-4~ est négatif : ~f_1~ est décroissante sur $\mathbb{R}$.
   b. ~f_2(x)=1/5x-7~, donc ~m=1/5~ est positif : ~f_2~ est croissante sur $\mathbb{R}$.
   c. ~f_3(x)=0x+3~, donc ~m=0~ : ~f_3~ est constante sur $\mathbb{R}$.
   d. ~f_4(x)=1/2-3/2x~, donc ~m=-3/2~ est négatif : ~f_4~ est décroissante sur $\mathbb{R}$.

2. ~f_1~ est décroissante. On calcule les images des bornes : ~f_1(-2)=8+1=9~ et ~f_1(3)=-12+1=-11~.

   ```variation
   variable: x
   domain: -2, 3

   variation: f_1(x)
     -2: 9, top
     3: -11, bottom
   ```
