Une fonction croissante conserve l'ordre : si ~a<b~, alors ~f(a)<f(b)~. Une fonction décroissante l'inverse : si ~a<b~, alors ~f(a)>f(b)~. On compare donc les nombres de départ, puis on utilise le sens de variation.

1. ~m=-3~ est négatif : ~f~ est décroissante sur $\mathbb{R}$, elle inverse l'ordre.
   a. ~1.4^2=1.96~ et ~1.96<2~, donc $1.4<\sqrt{2}$. Comme ~f~ est décroissante : $f(\sqrt{2})<f(1.4)$.
   b. ~\pi>3~, donc ~-\pi< -3~. Comme ~f~ est décroissante : ~f(-\pi)>f(-3)~.

2. ~g(x)=1/4x+1~ : ~m=1/4~ est positif, donc ~g~ est croissante sur $\mathbb{R}$, elle conserve l'ordre.

   ~0.001<0.01~, donc ~g(0.001)<g(0.01)~.

3. Le coefficient directeur de ~h~ est le taux d'accroissement entre ~2~ et ~7~ :

   $$\begin{align*}m&=\dfrac{h(7)-h(2)}{7-2}\\&=\dfrac{1-5}{5}\\&=-\dfrac{4}{5}\end{align*}$$

   ~m~ est négatif : ~h~ est décroissante sur $\mathbb{R}$.

   On pouvait aussi le voir sans calcul : ~2<7~ et ~h(2)>h(7)~, donc ~h~ n'est ni croissante ni constante ; une fonction affine qui n'est ni croissante ni constante est décroissante.
