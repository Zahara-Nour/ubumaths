L'expression ~mx+p~, avec ~m~ non nul, s'annule en ~x=-p/m~. Si ~m>0~, elle est négative puis positive ; si ~m<0~, elle est positive puis négative : c'est le signe de ~m~ à droite du zéro.

1. ~2x-6=0~ donne ~x=3~. ~m=2>0~ : l'expression est négative puis positive.

   ```variation
   variable: x
   domain: -inf, 3, +inf

   sign: 2x-6
     -inf,3: -
     3: z
     3,+inf: +
   ```

2. ~-3x+1=0~ donne ~x=1/3~. ~m=-3<0~ : l'expression est positive puis négative.

   ```variation
   variable: x
   domain: -inf, 1/3, +inf

   sign: -3x+1
     -inf,1/3: +
     1/3: z
     1/3,+inf: -
   ```

3. ~x/2+4=0~ donne ~x/2=-4~, soit ~x=-8~. ~m=1/2>0~ : l'expression est négative puis positive.

   ```variation
   variable: x
   domain: -inf, -8, +inf

   sign: x/2+4
     -inf,-8: -
     -8: z
     -8,+inf: +
   ```

4. ~5-2x=0~ donne ~x=5/2~. ~m=-2<0~ : l'expression est positive puis négative.

   ```variation
   variable: x
   domain: -inf, 5/2, +inf

   sign: 5-2x
     -inf,5/2: +
     5/2: z
     5/2,+inf: -
   ```
