Write each option as a function of the number of tickets, then compare: an equation for the same price, an inequality to find when B is cheaper.

1. ~f(x)=9x~: ~f~ is linear (the price is proportional to the number of tickets). ~g(x)=5x+36~: ~g~ is affine, not linear.
2. ~f(x)=g(x)~ gives ~9x=5x+36~, so ~4x=36~ and ~x=9~. For ~9~ tickets, both options cost ~f(9)=81~, that is €$81$.
3. ~g(x)<f(x)~ gives ~5x+36<9x~, so ~36<4x~ and ~x>9~. As the number of tickets is a whole number, **option B is the better deal from ~10~ tickets**.
