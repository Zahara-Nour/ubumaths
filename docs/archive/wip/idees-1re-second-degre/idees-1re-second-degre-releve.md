Chantier [`idees-1re-second-degre`](idees-1re-second-degre-progress.md). Les exercices de la rubrique
1AL2 d'une autre plateforme ont été lus dans leur code source local (copie nettoyée, anciennes
versions exclues). Il y en a **21**, pas 22 : le tableau de répartition comptait aussi le fichier de
test de 1AL20-1. Deux agents ont décrit les exercices. J'ai vérifié moi-même dans le code le tirage
de `choisiDelta` (a, b, c dans [−5 ; 5] privé de 0, rejetés jusqu'au signe de Δ voulu) et le fait
que 1AL24-2 est interactif.

publiés tagués sur les points de second degré de 1re spé, plus ceux de 1_GEN, 1_TECHNO et 2de. Les
ids d'exercice sont ceux de la plateforme. Programme :
`src/lib/server/programmes/transcriptions/1_SPE.md` § « Équations, fonctions polynômes du second
degré ».

## Ce que leur format fait et pas le nôtre

- **Une case « expression, ou bien impossible »** (1AL22-2, 1AL22-3) : un bouton « Pas factorisable »
  à côté de la saisie, qui est la bonne réponse quand Δ < 0. Chez nous, une case attend une
  expression, ou bien c'est un QCM ; pour les équations, l'ensemble vide ∅ fait l'affaire, mais pas
  pour une factorisation. Question Q1 à David, et ligne dans `outils-manquants.md` s'il la retient.
- **Questions enchaînées sur une même fonction** (1AL20-2, 1AL24-3 à 24-5) : déjà notées par
  `idees-1re-suites` (même question, non retenue comme outil). Nos questions restent indépendantes.
- Rien d'autre : la saisie d'un ensemble ({a ; b}, ∅, intervalles), la parabole tracée
  (` ```courbe `) et le tableau de variations à compléter (` ```variation ` à cases `?`) existent
  chez nous.
