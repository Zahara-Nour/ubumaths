# Relevé « suites numériques » de Première spécialité (2026-11-22)

Chantier [`idees-1re-suites`](idees-1re-suites-progress.md). Les 19 exercices de la rubrique 1AL1
d'une autre plateforme ont été lus dans leur code source local (copie nettoyée, anciennes versions
exclues). Deux agents ont décrit les exercices, puis j'ai vérifié dans le code les points
décisifs : q² et signe (1AL11-4), le choix « ni croissante ni décroissante » (1AL12-1), les cas
homographiques (1AL10-2) et les raisons −2 et 1/2 (1AL11-9). Ils sont comparés à nos modèles
relevés en prod le même jour (MCP lecture seule), soit 90 modèles tagués sur les points de suites
de 1re spé, plus ceux des autres niveaux. Les ids sont ceux de la plateforme. Programme :
`src/lib/server/programmes/transcriptions/1_SPE.md` § « Suites numériques, modèles discrets ».

## Ce que leur format fait et pas le nôtre

- **Questions enchaînées sur un même contexte** (1AL13-1) : un problème, quatre à six questions qui
  se suivent. Nos modèles posent une question chacun. `outils-manquants.md` n'en parle pas : la
  question est posée à David en phase 0 (Q3), et ne va dans la liste que s'il la retient.
- Rien d'autre : le placement de points sur un repère, les expressions en n et les QCM existent chez
  nous.
