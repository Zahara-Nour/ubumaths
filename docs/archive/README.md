## 📁 Structure

### `/sessions/`
Summaries de sessions de développement et debug.

Ces fichiers documentent les étapes de développement spécifiques mais ne sont plus pertinents pour la documentation active :

- Session summaries (QUESTION_DISPLAY_DEBUG.md, PRIVATE_MESSAGING_SESSION.md, etc.)
- Fix logs détaillés
- Debug logs

**Note** : Les informations importantes ont été consolidées dans la documentation principale.

### `/deprecated/`
Documentation de features ou composants obsolètes.

Conservés pour référence historique :

- Anciennes versions de composants (v1.0)
- Features retirées
- Anciennes architectures

## 🗑️ Politique de nettoyage

Les fichiers sont archivés ici plutôt que supprimés pour :

1. **Référence historique** : Comprendre l'évolution du projet
2. **Debugging** : Retrouver d'anciennes solutions
3. **Apprentissage** : Voir les erreurs passées pour ne pas les répéter

**Durée de conservation** : 6-12 mois après archivage, puis suppression si non utile.
