Pour comparer deux tarifs, on écrit chacun comme une fonction du nombre de places : l'égalité ~f(x)=g(x)~ donne le nombre de places pour lequel ils coûtent autant, l'inéquation ~g(x)<f(x)~ celles pour lesquelles le tarif B coûte moins cher.

1.  a. Tarif A : ~9*5=45~, soit $45$ €. Tarif B : ~36+5*5=36+25=61~, soit $61$ €. Pour ~5~ places, le tarif A est moins cher.
    b. Le tarif A coûte ~9~ € par place ; le tarif B, la carte plus ~5~ € par place :

    ~~f(x)=9x~~

    ~~g(x)=5x+36~~

    c. ~f(x)=9x~ est de la forme ~mx~ : ~f~ est une fonction **linéaire**. Le prix est proportionnel au nombre de places (coefficient ~9~).

    ~g(x)=5x+36~ est de la forme ~mx+p~ avec ~p=36~ non nul : ~g~ est affine, mais pas linéaire. Le prix n'est pas proportionnel au nombre de places (la carte coûte $36$ € même sans aucune place).

2.  a. On résout ~f(x)=g(x)~ :

    ~~9x=5x+36~~

    ~~4x=36~~

    ~~x=9~~

    Les deux tarifs coûtent autant pour ~9~ places : ~f(9)=9*9=81~ et ~g(9)=5*9+36=81~, soit $81$ €.

    b. On résout ~g(x)<f(x)~ :

    ~~5x+36<9x~~

    ~~36<4x~~

    ~~x>9~~

    On a divisé par ~4~, un nombre positif : le sens de l'inégalité ne change pas.

    c. ~x~ est un nombre entier de places. Le tarif B est strictement moins cher dès que ~x>9~ : **à partir de ~10~ places**, le tarif B est le plus avantageux. Pour ~9~ places, les deux tarifs se valent ; en dessous, le tarif A est moins cher.
