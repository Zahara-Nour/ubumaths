Augmenter un nombre de $t\,\%$, c'est le multiplier par $1+\dfrac{t}{100}$ ; le diminuer de $t\,\%$, c'est le multiplier par $1-\dfrac{t}{100}$. Le nouveau prix est donc une fonction **linéaire** du prix initial : $x\mapsto kx$, où ~k~ est le coefficient multiplicateur.

1.  a. L'augmentation vaut ~0.2*50=10~ : le nouveau prix est ~50+10=60~, soit $60$ €.
    b. Le prix augmente de ~0.2x~, donc ~f(x)=x+0.2x=1.2x~.
    c. ~f(x)=1.2x~ est de la forme ~mx~ : ~f~ est une fonction linéaire, de coefficient ~1.2~. Le nouveau prix est proportionnel au prix initial.
2.  Le prix diminue de ~0.3x~, donc ~g(x)=x-0.3x=0.7x~. La fonction ~g~ est linéaire, de coefficient ~0.7~.
3.  a. Après l'augmentation, le prix est ~1.2x~. On lui applique la baisse de $30\,\%$ : on le multiplie par ~0.7~.

    ~~h(x)=0.7*1.2x=0.84x~~

    b. ~0.84=1-0.16~ : le prix final est ~x-0.16x~. Le prix a baissé de $16\,\%$, et non de $10\,\%$ : le client a tort. Les $30\,\%$ de baisse portent sur un prix déjà augmenté, plus grand que ~x~.

4.  On résout ~f(x)=54~ :

    ~~1.2x=54~~

    ~~x=54/1.2=45~~

    Le prix initial était $45$ €. Vérification : ~1.2*45=54~.
