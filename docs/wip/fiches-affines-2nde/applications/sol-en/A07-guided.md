An affine function $x\mapsto mx+p$ has a constant rate of change, equal to ~m~; it is linear (a proportional situation) when ~p=0~. If the rate of change varies from one interval to another, the function is not affine.

1.  a. ~y=4x~: ~y~ is proportional to ~x~ (a linear function with multiplier ~4~).
    b. ~y=x^2~: this is not an expression of the form ~mx+p~. For example, from ~x=0~ to ~x=1~ the area increases by ~1~; from ~x=1~ to ~x=2~ it increases by ~3~: the rate of change is not constant. ~y~ is **neither** proportional to ~x~ **nor** an affine function of ~x~.
    c. ~y=2x+5~: ~y~ is an affine function of ~x~ (~m=2~, ~p=5~), **not linear** because ~p=5~ is not zero. The price is not proportional to the number of items: ~2~ items cost €~9~, but ~4~ items cost €~13~, not €~18~.
2.  a. Rate of change between neighbouring columns:

    ~~{8-5}/{2-1}=3/1=3~~

    ~~{14-8}/{4-2}=6/2=3~~

    ~~{23-14}/{7-4}=9/3=3~~

    The rate is constant, equal to ~3~: ~y~ is an affine function of ~x~, with ~m=3~. Using the column ~x=1~: ~5=3*1+p~, so ~p=2~.

    ~~y=3x+2~~

    Check with the last column: ~3*7+2=23~.

    b. Rate of change between neighbouring columns:

    ~~{2-1}/{1-0}=1~~

    ~~{4-2}/{2-1}=2~~

    ~~{8-4}/{3-2}=4~~

    The rates ~1~, ~2~ and ~4~ are not equal: ~y~ is **not** an affine function of ~x~. (Here, ~y~ doubles each time ~x~ increases by ~1~.)
