The gradient of an affine function ~f(x)=mx+p~ is its rate of change $m=\dfrac{f(b)-f(a)}{b-a}$. If ~m<0~, the function is decreasing and ~f(x)~ is positive, then negative, on either side of the value where it is zero.

1.  a. Rate of change between ~-1~ and ~2~:

    ~~m={f(2)-f(-1)}/{2-(-1)}={-3-6}/3={-9}/3=-3~~

    b. ~f(-1)=6~ means ~-3*(-1)+p=6~, that is ~3+p=6~, so ~p=3~.

    ~~f(x)=-3x+3~~

    Check: ~f(2)=-6+3=-3~.

2.  ~m=-3<0~: ~f~ is decreasing on $\mathbb{R}$.
3.  a. Solve ~f(x)=0~:

    ~~-3x+3=0~~

    ~~-3x=-3~~

    ~~x=1~~

    $S=\{1\}$

    b. ~f~ is decreasing and equals zero at ~1~: ~f(x)~ is positive before ~1~ and negative after.

    ```variation
    variable: x

    sign: f(x)
    ```
