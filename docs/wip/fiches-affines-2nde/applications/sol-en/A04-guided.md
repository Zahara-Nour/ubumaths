To compare two prices, write each one as a function of the number of tickets: the equation ~f(x)=g(x)~ gives the number of tickets for which they cost the same, and the inequality ~g(x)<f(x)~ the numbers for which option B is cheaper.

1.  a. Option A: ~9*5=45~, that is €$45$. Option B: ~36+5*5=36+25=61~, that is €$61$. For ~5~ tickets, option A is cheaper.
    b. Option A costs €~9~ per ticket; option B, the card plus €~5~ per ticket:

    ~~f(x)=9x~~

    ~~g(x)=5x+36~~

    c. ~f(x)=9x~ has the form ~mx~: ~f~ is a **linear** function. The price is proportional to the number of tickets (multiplier ~9~).

    ~g(x)=5x+36~ has the form ~mx+p~ with ~p=36~ not zero: ~g~ is affine but not linear. The price is not proportional to the number of tickets (the card costs €$36$ even with no tickets at all).

2.  a. Solve ~f(x)=g(x)~:

    ~~9x=5x+36~~

    ~~4x=36~~

    ~~x=9~~

    Both options cost the same for ~9~ tickets: ~f(9)=9*9=81~ and ~g(9)=5*9+36=81~, that is €$81$.

    b. Solve ~g(x)<f(x)~:

    ~~5x+36<9x~~

    ~~36<4x~~

    ~~x>9~~

    We divided by ~4~, a positive number, so the inequality sign does not change.

    c. ~x~ is a whole number of tickets. Option B is strictly cheaper as soon as ~x>9~: **from ~10~ tickets**, option B is the better deal. For ~9~ tickets, both options cost the same; below that, option A is cheaper.
