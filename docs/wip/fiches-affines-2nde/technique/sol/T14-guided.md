On remplace ~f(x)~ par son expression, puis on isole ~x~. Dans une inéquation, diviser par un nombre négatif change le sens de l'inégalité.

1. On isole ~x~ :

   $$\begin{align*}-2x+3&=-7\\-2x&=-10\\x&=5\end{align*}$$

   $S=\{5\}$. Vérification : ~f(5)=-10+3=-7~.

2. On isole ~x~ :

   $$\begin{align*}-2x+3&<1\\-2x&<-2\end{align*}$$

   On divise par ~-2~, négatif : le sens change.

   ~~x>1~~

   $S=\,]1\,;+\infty[$

3. On isole ~x~ :

   $$\begin{align*}-2x+3&\geqslant 5\\-2x&\geqslant 2\end{align*}$$

   On divise par ~-2~, négatif : le sens change.

   ~~x<=-1~~

   $S=\,\left]-\infty\,;-1\right]$

Ces résultats s'accordent avec le sens de variation : ~m=-2~ est négatif, donc ~f~ est décroissante. Comme ~f(1)=1~, ~f(x)~ est inférieur à ~1~ exactement pour ~x>1~.
