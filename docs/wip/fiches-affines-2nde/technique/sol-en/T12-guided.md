The expression ~mx+p~, with ~m~ non-zero, equals zero at ~x=-p/m~. If ~m>0~, it is negative then positive; if ~m<0~, it is positive then negative: to the right of the zero, it has the sign of ~m~.

1. ~2x-6=0~ gives ~x=3~. ~m=2>0~: the expression is negative then positive.

   ```variation
   variable: x
   domain: -inf, 3, +inf

   sign: 2x-6
     -inf,3: -
     3: z
     3,+inf: +
   ```

2. ~-3x+1=0~ gives ~x=1/3~. ~m=-3<0~: the expression is positive then negative.

   ```variation
   variable: x
   domain: -inf, 1/3, +inf

   sign: -3x+1
     -inf,1/3: +
     1/3: z
     1/3,+inf: -
   ```

3. ~x/2+4=0~ gives ~x/2=-4~, that is ~x=-8~. ~m=1/2>0~: the expression is negative then positive.

   ```variation
   variable: x
   domain: -inf, -8, +inf

   sign: x/2+4
     -inf,-8: -
     -8: z
     -8,+inf: +
   ```

4. ~5-2x=0~ gives ~x=5/2~. ~m=-2<0~: the expression is positive then negative.

   ```variation
   variable: x
   domain: -inf, 5/2, +inf

   sign: 5-2x
     -inf,5/2: +
     5/2: z
     5/2,+inf: -
   ```
