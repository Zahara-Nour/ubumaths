An affine function ~f(x)=mx+p~ is increasing on $\mathbb{R}$ if ~m>0~, decreasing on $\mathbb{R}$ if ~m<0~, and constant if ~m=0~: the direction of variation is given by the sign of the gradient.

1.  a. ~m=-4~ is negative: ~f_1~ is decreasing on $\mathbb{R}$.
    b. ~f_2(x)=1/5x-7~, so ~m=1/5~ is positive: ~f_2~ is increasing on $\mathbb{R}$.
    c. ~f_3(x)=0x+3~, so ~m=0~: ~f_3~ is constant on $\mathbb{R}$.
    d. ~f_4(x)=1/2-3/2x~, so ~m=-3/2~ is negative: ~f_4~ is decreasing on $\mathbb{R}$.

2.  ~f_1~ is decreasing. We work out the images of the endpoints: ~f_1(-2)=8+1=9~ and ~f_1(3)=-12+1=-11~.

    ```variation
    variable: x
    domain: -2, 3

    variation: f_1(x)
      -2: 9, top
      3: -11, bottom
    ```
