# Boutique d'avatars — prompts du premier lot (Nano Banana)

Version 5, retenue le 2026-11-15 : la chandelle verte (n° 1) est validée par David et sert de **référence de style** aux 20 autres. Leçons des versions 1 à 4 : pas de nuancier joint (il se retrouvait dans l'image), pas de nom d'artiste, pas de « student » (l'IA dessinait un élève), des phrases plutôt que des puces, trait épais, et **une liste fermée de couleurs par avatar** (avec les 7 couleurs, l'IA les mettait toutes).

Conversion : `pnpm avatars:convertir <dossier>` rogne le fond et agrandit le sujet au maximum dans le cercle ; la marge laissée par l'IA n'a donc pas d'importance.

Une nouvelle conversation par image, **sans pièce jointe**. Les prompts sont rédigés en phrases (Nano Banana suit mieux une description qu'une liste de mots-clés). Si l'image sort rectangulaire, redemander dans la même conversation : « Make it square, 1:1. »

Quand un premier avatar te plaît : joins-le aux suivants et ajoute à la fin du prompt : « Use the same drawing style as the attached image, but draw only this new subject. »

Enregistrer chaque image sous le nom indiqué, toutes dans un même dossier.
