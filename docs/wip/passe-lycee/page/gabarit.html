Passe des points du lycée

Étape a : chaque fiche propose une coupe, un archivage, un point ⚙ ou une puce rétablie, avec la ligne du BO. Les fiches « à trancher » portent une vraie question : la recommandation est dans le texte. Les autres appliquent les règles que tu as tranchées (1a, 1b, T1 à T6) : réponds OK, ou « À revoir » avec un commentaire.

Commence par les questions : chacune montre la ligne du BO, le point actuel et ce que donne chaque option ; clique sur l'option que tu choisis. Elles tranchent toutes les fiches marquées « à trancher ». Le bouton en tête de chaque programme marque OK d'un coup les fiches auxquelles tu n'as pas répondu ; « À revoir » reste possible ensuite.

Le premier libellé d'une coupe garde le code actuel ; « neuf » reçoit un nouveau code, rangé juste après.
