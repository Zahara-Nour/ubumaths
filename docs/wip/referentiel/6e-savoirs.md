## Note transversale — Algorithmique et programmation

En 6ᵉ, l'algorithmique n'est généralement **pas un thème séparé** mais est introduite de manière intégrée dans les autres thèmes (constructions géométriques pas à pas, suites d'instructions de calcul, premiers contacts avec Scratch). Selon l'organisation pédagogique choisie, deux options :

**Option A** — Considérer Scratch / algorithmique comme **intégré** aux objectifs existants (par exemple un objectif « Construire avec Scratch » dans le thème Espace et géométrie). Ne pas créer de 5ᵉ thème.

**Option B** — Créer un 5ᵉ thème léger « Initiation à l'algorithmique » avec 1–2 objectifs :

- Objectif 5.1 — Exécuter et écrire des suites d'instructions simples (Scratch)
- Objectif 5.2 — Construire des figures simples à l'aide de Scratch ou tortue

⚠️ À trancher selon ton projet pédagogique.

## Comment compléter cette trame

Pour chaque objectif :

1. **Vérifier le libellé** contre le BO officiel (eduscol).
2. **Identifier les capacités** : ce sont les sous-tâches qu'on peut évaluer par une question unique. Cible : 3–6 par objectif.
3. **Rédiger les 4 indicateurs** de chaque capacité. Rappel : l'indicateur d'un niveau **est ce qui permet de dire si ce niveau est validé**.
4. **Marquer `is_progressive: false`** seulement si l'échelle n'est pas strictement progressive (cas exceptionnel).

**Exemple complété** (objectif 1.3) :

```
### Objectif 1.3 — Comprendre et utiliser les fractions simples

**Capacités** :

- [x] Identifier la fraction associée à un partage
  - is_progressive: true
  - Niveau 1 — N'identifie pas le numérateur et le dénominateur.
  - Niveau 2 — Identifie correctement les deux termes mais inverse leur rôle.
  - Niveau 3 — Identifie correctement la fraction pour un partage en parts égales (entiers ≤ 10).
  - Niveau 4 — Identifie la fraction y compris dans des contextes complexes (parts non équidistantes, partage d'un ensemble).
```
