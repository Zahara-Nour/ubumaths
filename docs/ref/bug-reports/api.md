## Vue d'ensemble

| Endpoint                           | Methode | Auth       | Description          |
| ---------------------------------- | ------- | ---------- | -------------------- |
| `/api/bug-reports`                 | GET     | User/Admin | Lister les rapports  |
| `/api/bug-reports`                 | POST    | User       | Creer un rapport     |
| `/api/bug-reports/[id]`            | GET     | User/Admin | Details d'un rapport |

## Authentication

Tous les endpoints necessitent une authentification.

```typescript
// Middleware utilise
import { requireAuth } from '$lib/server/middleware/auth';

const { user, profile } = await requireAuth(locals);
```

| Code | Message            | Cause                       |
| ---- | ------------------ | --------------------------- |
| 401  | Non authentifie    | Session invalide ou expiree |
| 403  | Acces non autorise | Role insuffisant            |

## Endpoints

### List Bug Reports

```http
GET /api/bug-reports
```

Liste les rapports de bugs. Les utilisateurs voient leurs propres rapports, les admins voient tous les rapports.

#### Query Parameters

| Parametre  | Type   | Default | Description                     |
| ---------- | ------ | ------- | ------------------------------- |
| `status`   | string | -       | Filtrer par statut              |
| `category` | string | -       | Filtrer par categorie           |
| `severity` | string | -       | Filtrer par severite            |
| `limit`    | number | 20      | Nombre max de resultats (1-100) |
| `offset`   | number | 0       | Pagination offset               |

#### Response

```typescript
interface ListBugReportsResponse {
	reports: BugReportWithAuthor[];
	total: number;
	limit: number;
	offset: number;
}

interface BugReportWithAuthor {
	id: string;
	user_id: string;
	category: 'bug' | 'content' | 'ux' | 'feature' | 'other';
	severity: 'low' | 'medium' | 'high' | 'critical';
	title: string;
	description: string;
	screenshot_url: string | null;
	screenshot_path: string | null;
	page_url: string | null;
	user_agent: string | null;
	viewport_size: string | null;
	session_context: object;
	status: 'pending' | 'acknowledged' | 'in_progress' | 'resolved' | 'wont_fix' | 'duplicate';
	resolution_notes: string | null;
	resolved_by: string | null;
	resolved_at: string | null;
	auto_generated: boolean;
	created_at: string;
	updated_at: string;
	author?: {
		id: string;
		full_name: string | null;
		email: string;
		role: string;
	};
	resolver?: {
		id: string;
		full_name: string | null;
	};
}
```

#### Exemple

```typescript
// Fetch pending bug reports
const response = await fetch('/api/bug-reports?status=pending&limit=10');
const data = await response.json();

console.log(`${data.total} rapports pending, affichage de ${data.reports.length}`);
```

### Create Bug Report

```http
POST /api/bug-reports
```

Cree un nouveau rapport de bug.

#### Request Body

```typescript
interface CreateBugReportRequest {
	category: 'bug' | 'content' | 'ux' | 'feature' | 'other';
	severity?: 'low' | 'medium' | 'high' | 'critical'; // default: 'medium'
	title: string; // 5-200 caracteres
	description: string; // 20-5000 caracteres
	pageUrl?: string; // max 500 caracteres
	userAgent?: string; // max 500 caracteres
	viewportSize?: string; // format: "1920x1080"
	sessionContext?: {
		freezeEvents?: FreezeEvent[];
		recentActions?: UserAction[];
		webVitals?: WebVitalsMetrics;
		exerciseId?: string;
		exerciseType?: string;
		classId?: string;
		assignmentId?: string;
	};
	screenshotUrl?: string;
	screenshotPath?: string;
	autoGenerated?: boolean; // default: false
}
```

#### Response

```typescript
{
  success: true,
  report: BugReport
}
```

#### Enrichissement automatique

Le serveur enrichit automatiquement le `sessionContext` avec:

1. **Recent errors** (5 derniere minutes) depuis `error_logs`
2. **Slow requests** depuis `error_logs`

```typescript
// Server-side enrichment (POST handler)
const { data: recentErrors } = await supabase
	.from('error_logs')
	.select('id, error_type, message, severity, created_at, url, file_path, line_number, stack_trace')
	.eq('user_id', user.id)
	.gte('created_at', fiveMinutesAgo)
	.order('created_at', { ascending: false })
	.limit(10);
```

#### Exemple complet

```typescript
import { getFreezeDetectionContext } from '$lib/utils/freezeDetection';

const response = await fetch('/api/bug-reports', {
	method: 'POST',
	headers: { 'Content-Type': 'application/json' },
	body: JSON.stringify({
		category: 'bug',
		severity: 'high',
		title: 'Erreur lors de la soumission du formulaire',
		description: `
      ## Etapes pour reproduire
      1. Aller sur la page d'exercice
      2. Repondre a toutes les questions
      3. Cliquer sur "Soumettre"
      4. L'ecran se fige pendant 10 secondes

      ## Comportement attendu
      Le formulaire devrait etre soumis immediatement.

      ## Comportement observe
      Freeze de l'interface pendant environ 10 secondes.
    `.trim(),
		pageUrl: window.location.href,
		userAgent: navigator.userAgent,
		viewportSize: `${window.innerWidth}x${window.innerHeight}`,
		sessionContext: {
			...getFreezeDetectionContext(),
			exerciseId: currentExercise?.id
		}
	})
});

if (!response.ok) {
	const error = await response.json();
	throw new Error(error.message);
}

const { report } = await response.json();
console.log('Rapport cree:', report.id);
```

### Get Bug Report

```http
GET /api/bug-reports/[reportId]
```

Recupere les details d'un rapport.

#### Path Parameters

| Parametre  | Type | Description   |
| ---------- | ---- | ------------- |
| `reportId` | UUID | ID du rapport |

#### Response

```typescript
{
	report: BugReportWithAuthor;
}
```

#### Autorisations

- **Users**: Peuvent voir leurs propres rapports uniquement
- **Admins**: Peuvent voir tous les rapports

#### Exemple

```typescript
const response = await fetch(`/api/bug-reports/${reportId}`);

if (response.status === 404) {
	console.log('Rapport non trouve');

}

if (response.status === 403) {
	console.log('Acces refuse');
	return;
}

const { report } = await response.json();
```

### Update Bug Report

```http
PATCH /api/bug-reports/[reportId]
```

Met a jour un rapport. Les champs modifiables dependent du role.

#### Path Parameters

| Parametre  | Type | Description   |
| ---------- | ---- | ------------- |
| `reportId` | UUID | ID du rapport |

#### Request Body (User)

Utilisateurs peuvent modifier uniquement leurs rapports **pending**.

```typescript
interface UpdateBugReportUserRequest {
	title?: string; // 5-200 caracteres
	description?: string; // 20-5000 caracteres
}
```

#### Request Body (Admin)

Admins peuvent modifier tous les rapports.

```typescript
interface UpdateBugReportAdminRequest {
	status?: 'pending' | 'acknowledged' | 'in_progress' | 'resolved' | 'wont_fix' | 'duplicate';
	resolutionNotes?: string; // max 2000 caracteres
}
```

#### Response

```typescript
{
  success: true,
  report: BugReport
}
```

#### Comportement automatique (Admin)

Quand le statut passe a `resolved`, `wont_fix`, ou `duplicate`:

- `resolved_by` est set automatiquement a l'admin courant
- `resolved_at` est set automatiquement a maintenant

```typescript
// Server-side logic
if (['resolved', 'wont_fix', 'duplicate'].includes(validation.data.status)) {
	updateData.resolved_by = user.id;
	updateData.resolved_at = new Date().toISOString();
}
```

#### Exemples

**User update (pending report only):**

```typescript
const response = await fetch(`/api/bug-reports/${reportId}`, {
	method: 'PATCH',
	headers: { 'Content-Type': 'application/json' },
	body: JSON.stringify({
		title: 'Titre corrige',
		description: 'Description mise a jour avec plus de details...'
	})
});
```

**Admin update:**

```typescript
const response = await fetch(`/api/bug-reports/${reportId}`, {
	method: 'PATCH',
	headers: { 'Content-Type': 'application/json' },
	body: JSON.stringify({
		status: 'resolved',
		resolutionNotes: 'Corrige dans le commit abc123. Le probleme etait...'
	})
});
```

### Upload Screenshot

```http
POST /api/bug-reports/[reportId]/screenshot
```

Upload une capture d'ecran pour un rapport existant.

#### Path Parameters

| Parametre  | Type | Description   |
| ---------- | ---- | ------------- |
| `reportId` | UUID | ID du rapport |

#### Request

- **Content-Type**: `multipart/form-data`
- **Field name**: `image`
- **Max size**: 5MB
- **Allowed types**: `image/jpeg`, `image/png`, `image/gif`, `image/webp`

#### Validation

1. **Taille**: Max 5MB
2. **MIME type**: Whitelist
3. **Magic bytes**: Verification de la signature du fichier

```typescript
// Server-side validation
const signatureValid = validateFileSignature(buffer, file.type);
if (!signatureValid) {
	throw error(400, 'Signature de fichier invalide');
}
```

#### Response

```typescript
{
  success: true,
  data: {
    url: string;      // URL publique
    path: string;     // Chemin storage
    size: number;     // Taille en bytes
    mimeType: string; // Type MIME
  }
}
```

#### Comportement

- Remplace la capture existante si presente
- Stocke dans `{user_id}/{report_id}/{timestamp}.{ext}`
- Met a jour `screenshot_url` et `screenshot_path` du rapport

#### Exemple

```typescript
const formData = new FormData();
formData.append('image', screenshotFile);

const response = await fetch(`/api/bug-reports/${reportId}/screenshot`, {
	method: 'POST',
	body: formData
});

if (!response.ok) {
	const error = await response.json();
	console.error('Upload failed:', error.message);
	return;
}

const { data } = await response.json();
console.log('Screenshot uploaded:', data.url);
```

## Validation Schemas

### createBugReportSchema

```typescript
import { z } from 'zod';

export const createBugReportSchema = z.object({
	category: z.enum(['bug', 'content', 'ux', 'feature', 'other']),
	severity: z.enum(['low', 'medium', 'high', 'critical']).default('medium'),
	title: z
		.string()
		.min(5, 'Le titre doit contenir au moins 5 caracteres')
		.max(200, 'Le titre ne peut pas depasser 200 caracteres')
		.transform((s) => s.trim()),
	description: z
		.string()
		.min(20, 'La description doit contenir au moins 20 caracteres')
		.max(5000, 'La description ne peut pas depasser 5000 caracteres')
		.transform((s) => s.trim()),
	pageUrl: z.string().max(500).optional(),
	userAgent: z.string().max(500).optional(),
	viewportSize: z
		.string()
		.max(20)
		.regex(/^\d+x\d+$/, 'Format viewport invalide (ex: 1920x1080)')
		.optional(),
	sessionContext: sessionContextSchema.optional(),
	screenshotUrl: z.string().url().optional(),
	screenshotPath: z.string().max(500).optional(),
	autoGenerated: z.boolean().default(false)
});
```

### updateBugReportUserSchema


## Error Handling

### Format des erreurs

```typescript
{
	message: string; // Message d'erreur en francais
}
```

### Codes HTTP

| Code | Description  | Cause commune             |
| ---- | ------------ | ------------------------- |
| 400  | Bad Request  | Validation Zod echouee    |
| 401  | Unauthorized | Session invalide          |
| 403  | Forbidden    | Permissions insuffisantes |
| 404  | Not Found    | Rapport inexistant        |
| 500  | Server Error | Erreur base de donnees    |

### Pattern de gestion

```typescript
// Server-side error handling pattern
try {
	// Business logic
} catch (err) {
	if (err && typeof err === 'object' && 'status' in err) {
		throw err; // Re-throw SvelteKit errors
	}
	console.error('[API] Unexpected error:', err);
	throw error(500, 'Une erreur inattendue est survenue');
}
```

### Exemple client

```typescript
async function createBugReport(data: CreateBugReportRequest) {
	const response = await fetch('/api/bug-reports', {
		method: 'POST',
		headers: { 'Content-Type': 'application/json' },
		body: JSON.stringify(data)
	});

	if (!response.ok) {
		const error = await response.json();

		switch (response.status) {
			case 400:
				throw new ValidationError(error.message);
			case 401:
				throw new AuthError('Session expiree');
			case 403:
				throw new AuthError('Acces refuse');
			default:
				throw new Error(error.message || 'Erreur serveur');
		}
	}

	return response.json();
}
```
