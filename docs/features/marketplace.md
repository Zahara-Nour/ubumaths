# Marketplace - Guide Utilisateur

## Vue d'ensemble

Le marketplace UbuMaths permet aux étudiants d'échanger leurs cartes VIP et leurs gidouilles (monnaie virtuelle) dans un environnement sûr et contrôlé. Cette fonctionnalité favorise l'engagement des étudiants et ajoute une dimension sociale à l'apprentissage.

---

## Fonctionnalités pour les Étudiants

### Créer une Annonce

Les étudiants peuvent créer deux types d'annonces :

#### Annonce de Vente

- **But** : Vendre des cartes VIP ou des gidouilles contre d'autres cartes ou gidouilles
- **Processus** :
  1. Accéder à "Tableau de bord" > "Marketplace"
  2. Cliquer sur "Créer une annonce"
  3. Sélectionner "Vente"
  4. Choisir ce que vous offrez (cartes VIP et/ou gidouilles)
  5. Spécifier ce que vous voulez en échange
  6. Ajouter un titre et une description (optionnel)
  7. Définir la durée de l'annonce (1-30 jours)
  8. Publier l'annonce

#### Annonce d'Achat

- **But** : Rechercher des cartes VIP spécifiques en offrant vos ressources
- **Processus** : Similaire à l'annonce de vente, mais inversé

**Limites** :

- Maximum 5 annonces actives par étudiant
- Les cartes utilisées dans une annonce sont verrouillées
- Les annonces expirent automatiquement après la durée définie

### Faire une Proposition

Les étudiants peuvent répondre aux annonces des autres :

1. **Parcourir les annonces** : Utiliser les filtres (type, rareté, prix)
2. **Voir les détails** : Cliquer sur une annonce pour voir tous les détails
3. **Faire une proposition** :
   - Sélectionner les cartes/gidouilles à offrir
   - Ajouter un message optionnel
   - Envoyer la proposition
4. **Suivi** : Voir l'état dans "Mes annonces" > "Propositions reçues"

**Important** :

- Une seule proposition par annonce
- Les cartes proposées sont verrouillées jusqu'à la réponse
- Les propositions peuvent être retirées tant qu'elles sont en attente

### Échanges Directs entre Amis

Les étudiants peuvent négocier directement avec leurs amis :

#### Initier un Échange

1. Accéder à "Marketplace" > "Mes échanges"
2. Cliquer sur "Nouvel échange"
3. Sélectionner un ami
4. Construire l'offre initiale :
   - Choisir vos cartes/gidouilles
   - Spécifier ce que vous voulez de votre ami
5. Envoyer l'offre

#### Négociation

- **Contre-offres** : Modifier les termes et renvoyer
- **Messages** : Ajouter un message optionnel avec chaque offre
- **Indicateur "À votre tour"** : Savoir quand c'est votre tour
- **Historique** : Voir toutes les offres précédentes

> **Note**: Le chat en temps réel est prévu pour une future mise à jour. Pour l'instant, utilise le champ "Message" dans chaque offre.

#### Finaliser l'Échange

- Accepter l'offre actuelle pour exécuter l'échange
- Les cartes et gidouilles sont transférés automatiquement
- L'échange est enregistré dans l'historique

**Sécurité** :

- Limite de 10 échanges par jour
- Les cartes sont verrouillées pendant la négociation
- Transactions atomiques (tout ou rien)

### Gestion des Cartes Verrouillées

Les cartes peuvent être verrouillées pour trois raisons :

- **Dans une annonce** : Verrouillée jusqu'à expiration/annulation
- **Dans une proposition** : Verrouillée jusqu'à réponse
- **Dans un échange** : Verrouillée jusqu'à finalisation

**Déblocage automatique** :

- Annonce expirée ou annulée
- Proposition rejetée ou retirée
- Échange complété ou annulé

## Fonctionnalités pour les Enseignants

### Tableau de Bord des Analyses

Les enseignants ont accès à des analyses détaillées :

#### Métriques d'Engagement

- **Traders actifs** : Nombre d'étudiants ayant fait au moins un échange
- **Pourcentage d'activité** : Proportion d'étudiants actifs
- **Tendances temporelles** : Graphiques d'activité sur 7/30 jours

#### Métriques Économiques

- **Gidouilles en circulation** : Total échangé
- **Moyenne par échange** : Valeur moyenne des transactions
- **Distribution** : Répartition des types d'échanges

#### Statistiques des Cartes

- **Cartes les plus échangées** : Top 10 des templates
- **Cartes uniques échangées** : Diversité des échanges
- **Rareté des échanges** : Distribution par rareté

#### Analyses Temporelles

- **Heures de pointe** : Moments de forte activité
- **Jours actifs** : Répartition par jour de la semaine
- **Évolution mensuelle** : Tendances à long terme

**Filtres disponibles** :

- Par classe
- Par période (7, 30, 90 jours, personnalisé)
- Par type d'activité

### Suivi d'Activité en Temps Réel

Le flux d'activité permet de :

- Voir les échanges en temps réel
- Identifier les comportements suspects
- Suivre l'engagement des étudiants
- Filtrer par type d'activité

**Types d'événements suivis** :

- Création d'annonce
- Proposition acceptée
- Échange complété
- Annonce expirée

### Configuration du Marketplace

Les enseignants peuvent configurer :

#### Au Niveau de la Classe

- **Activer/Désactiver** : Contrôle total sur l'accès
- **Limites d'annonces** : 1-20 annonces actives par étudiant
- **Limites d'échanges** : 1-100 échanges par jour
- **Durée des annonces** : 1-30 jours par défaut

#### Limites de Trading

- **Gidouilles min/max** : Encadrer les montants
- **Cartes maximum** : Limiter la taille des échanges
- **Cooldown** : Délai entre les échanges

### Modération

Les enseignants peuvent :

- **Voir tous les échanges** : Historique complet de la classe
- **Analyser les patterns** : Détecter les abus potentiels
- **Intervenir** : Contacter les étudiants si nécessaire

**Indicateurs d'alerte** :

- Volume d'échanges inhabituel
- Concentration de richesse
- Patterns de manipulation

## Meilleures Pratiques

### Pour les Étudiants

1. **Titres descriptifs** : Utilisez des titres clairs pour vos annonces
2. **Prix justes** : Recherchez les prix du marché avant de poster
3. **Communication** : Utilisez le chat dans les échanges directs
4. **Patience** : Attendez les bonnes offres
5. **Diversification** : Ne mettez pas toutes vos cartes dans une annonce

### Pour les Enseignants

1. **Configuration initiale** :
   - Commencez avec des limites conservatrices
   - Augmentez progressivement selon l'engagement

2. **Suivi régulier** :
   - Vérifiez les analyses hebdomadairement
   - Identifiez les étudiants peu engagés
   - Récompensez les comportements positifs

3. **Communication** :
   - Expliquez les règles clairement
   - Encouragez le fair-play
   - Célébrez les échanges réussis

4. **Intervention** :
   - Agissez rapidement sur les comportements suspects
   - Éduquez plutôt que punir
   - Ajustez les limites si nécessaire

## Résolution de Problèmes

### Problèmes Courants

#### "Mes cartes sont verrouillées"

**Causes** :

- Carte utilisée dans une annonce active
- Carte dans une proposition en attente
- Carte dans un échange en cours

**Solutions** :

- Vérifier "Mes annonces" et annuler si nécessaire
- Vérifier "Mes échanges" et finaliser/annuler
- Attendre l'expiration automatique

#### "Je ne peux pas créer d'annonce"

**Causes** :

- Limite d'annonces actives atteinte (5 par défaut)
- Marketplace désactivé pour votre classe
- Pas de cartes/gidouilles disponibles

**Solutions** :

- Annuler ou attendre l'expiration d'annonces existantes
- Contacter votre enseignant
- Gagner des ressources par les activités

#### "L'échange a échoué"

**Causes** :

- L'autre partie n'a plus les ressources
- Limite quotidienne atteinte
- Problème de connexion

**Solutions** :

- Réessayer plus tard
- Vérifier votre limite quotidienne
- Rafraîchir la page

#### "Je ne vois pas les annonces"

**Causes** :

- Marketplace désactivé
- Filtres trop restrictifs
- Pas d'annonces actives dans votre école

**Solutions** :

- Vérifier avec l'enseignant
- Réinitialiser les filtres
- Créer vos propres annonces

## FAQ

### Général

**Q : Puis-je échanger avec des étudiants d'autres écoles ?**
R : Non, les échanges sont limités à votre école pour des raisons de sécurité et d'équité.

**Q : Mes cartes peuvent-elles être volées ?**
R : Non, toutes les transactions sont sécurisées et nécessitent votre accord explicite.

**Q : Que se passe-t-il si j'ai été trompé ?**
R : Contactez votre enseignant. Les transactions sont enregistrées et peuvent être examinées.

### Annonces

**Q : Combien de temps durent les annonces ?**
R : Entre 1 et 30 jours selon votre choix. La durée par défaut est 7 jours.

**Q : Puis-je modifier une annonce après publication ?**
R : Non, mais vous pouvez l'annuler et en créer une nouvelle.

**Q : Que se passe-t-il aux propositions quand j'accepte une offre ?**
R : Toutes les autres propositions sont automatiquement rejetées et les cartes débloquées.

### Échanges Directs

**Q : Puis-je échanger avec quelqu'un qui n'est pas mon ami ?**
R : Pas directement. Utilisez les annonces publiques ou ajoutez-le d'abord comme ami.

**Q : Y a-t-il une limite au nombre de contre-offres ?**
R : Non, vous pouvez négocier autant que nécessaire.

**Q : Puis-je envoyer des messages pendant la négociation ?**
R : Oui, tu peux inclure un message optionnel avec chaque offre ou contre-offre. Un chat en temps réel sera ajouté dans une future version.

### Limites

**Q : Pourquoi y a-t-il des limites ?**
R : Pour maintenir l'équité, prévenir les abus et encourager une participation réfléchie.

**Q : Les limites peuvent-elles être modifiées ?**
R : Oui, votre enseignant peut ajuster les limites selon les besoins de la classe.

**Q : Que compte comme "un échange" dans la limite quotidienne ?**
R : Chaque transaction complétée (annonce acceptée ou échange direct finalisé).

## Conseils Avancés

### Stratégies de Trading

1. **Timing** : Les nouvelles cartes ont plus de valeur juste après leur sortie
2. **Rareté** : Les cartes légendaires valent généralement 3-5 cartes communes
3. **Collections** : Les sets complets valent plus que la somme des parties
4. **Patience** : Ne pas accepter la première offre, sauf si elle est excellente

### Optimisation des Annonces

1. **Titre accrocheur** : "URGENT", "RARE", "BON DEAL" attirent l'attention
2. **Description détaillée** : Expliquez pourquoi votre offre est intéressante
3. **Flexibilité** : Indiquez si vous êtes ouvert aux négociations
4. **Timing** : Postez quand les étudiants sont actifs (pauses, après les cours)

### Gestion de Collection

1. **Inventaire** : Gardez trace de vos cartes importantes
2. **Objectifs** : Définissez ce que vous voulez collecter
3. **Diversification** : Ne misez pas tout sur une seule carte
4. **Réserves** : Gardez des gidouilles pour les opportunités
