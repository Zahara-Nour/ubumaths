# Matériel Pédagogique Google Classroom

**Statut** : ✅ Production
**Date de mise à jour** : 2025-11-15

## Vue d'ensemble

Le système de matériel pédagogique permet aux enseignants de synchroniser et partager des documents non-évalués depuis Google Classroom (vidéos, PDFs, liens) avec leurs classes UbuMaths. Les élèves peuvent consulter ces ressources organisées par catégorie ou rubrique.

### Fonctionnalités principales

- ✅ **Synchronisation Google Classroom** - Récupération automatique des matériaux pédagogiques
- ✅ **Organisation hybride** - Par rubriques Google OU catégories UbuMaths
- ✅ **Partage multi-classes** - Partager avec plusieurs classes simultanément
- ✅ **Visibilité contrôlée** - Activer/désactiver la visibilité pour les élèves
- ✅ **Descriptions personnalisées** - Ajouter des notes par classe
- ✅ **Pagination et filtres** - Interface élève optimisée avec filtres par classe/catégorie/rubrique

## Pour les enseignants

### 1. Prérequis

Avant de partager du matériel pédagogique, vous devez :

1. **Connecter votre compte Google** (voir [Guide de configuration Google Classroom](../guides/google-classroom-setup.md))
2. **Synchroniser vos cours Google Classroom**
3. **Créer au moins une classe dans UbuMaths**

### 2. Synchroniser le matériel pédagogique

#### Accéder au tableau de bord Google Classroom

1. Connectez-vous à UbuMaths
2. Naviguez vers **Tableau de bord enseignant** → **Google Classroom**
3. Cliquez sur **Synchroniser** pour mettre à jour vos cours et matériaux

#### Qu'est-ce qui est synchronisé ?

Le système récupère automatiquement :

- **Rubriques/Thèmes** (Topics) - Organisation des cours Google
- **Matériaux pédagogiques** (CourseWorkMaterials) - Documents non-évalués :
  - Fichiers Google Drive (PDF, docs, présentations)
  - Vidéos YouTube
  - Liens externes
  - Formulaires Google
- **Pièces jointes** - Fichiers et ressources liés aux matériaux

**Note** : Seuls les matériaux **publiés** sont synchronisés (les brouillons sont ignorés).

### 3. Partager du matériel avec vos classes

#### Étape par étape

1. **Accéder au matériel**
   - Dans votre tableau de bord Google Classroom
   - Cliquez sur un cours pour voir ses matériaux

2. **Sélectionner un matériel**
   - Cliquez sur **Partager** à côté du matériel souhaité
   - Le dialogue de partage s'ouvre

3. **Configurer le partage**

   Pour chaque classe, vous pouvez :
   - ✅ **Sélectionner la classe** - Cochez les classes destinataires
   - 👁️ **Visibilité** - Activer/désactiver pour les élèves (brouillon si désactivé)
   - 📁 **Organisation** - Choisir entre :
     - **Par rubrique Google** - Utilise les Topics de Google Classroom
     - **Par catégorie UbuMaths** - Utilise vos catégories personnalisées
   - 📝 **Description personnalisée** - Ajouter une note spécifique à cette classe (remplace la description originale)

4. **Valider le partage**
   - Cliquez sur **Partager**
   - Le matériel apparaît immédiatement pour les élèves (si visible)

#### Organisation : Rubriques vs Catégories

Vous avez le choix entre deux modes d'organisation **par classe** :

| Mode                    | Description                            | Avantages                                                                                                                      |
| ----------------------- | -------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| **Rubriques Google**    | Utilise les Topics de Google Classroom | - Cohérence avec Google Classroom<br>- Organisation automatique par rubrique                                                   |
| **Catégories UbuMaths** | Utilise vos catégories personnalisées  | - Organisation personnalisée<br>- 5 catégories par défaut : 📚 Cours, ✏️ Exercices, ✅ Corrections, 📝 Devoirs, 🎯 Évaluations |

**Important** : Vous pouvez choisir un mode différent pour chaque classe. Par exemple :

- Classe A : Organisation par rubriques Google
- Classe B : Organisation par catégories UbuMaths

### 4. Gérer les catégories UbuMaths

#### Catégories par défaut

Lors de la liaison d'un cours Google à une classe UbuMaths, 5 catégories sont créées automatiquement :

1. 📚 **Cours** (bleu) - Leçons, théorie
2. ✏️ **Exercices** (vert) - Pratique, entraînement
3. ✅ **Corrections** (violet) - Solutions, corrigés
4. 📝 **Devoirs** (orange) - Travail à la maison
5. 🎯 **Évaluations** (rouge) - Contrôles, tests

#### Créer des catégories personnalisées

1. Naviguez vers **Paramètres de la classe**
2. Section **Catégories de matériel**
3. Cliquez sur **Nouvelle catégorie**
4. Configurez :
   - Nom (ex: "Vidéos", "Ressources complémentaires")
   - Icône emoji (optionnel)
   - Couleur (hex, ex: #3B82F6)
   - Ordre d'affichage (numéro)

### 5. Modifier ou supprimer un partage

#### Modifier la visibilité

1. Accédez au matériel partagé
2. Cliquez sur **Modifier le partage**
3. Changez la configuration (visibilité, catégorie, description)
4. Sauvegardez

#### Supprimer un partage

1. Accédez au matériel partagé
2. Cliquez sur **Supprimer le partage** pour une classe spécifique
3. Confirmez

**Note** : La suppression du partage ne supprime pas le matériel de Google Classroom, seulement l'accès dans UbuMaths.

### 6. Bonnes pratiques

#### Organisation efficace

- ✅ **Utilisez les rubriques** si vous organisez déjà vos cours dans Google Classroom
- ✅ **Utilisez les catégories** si vous préférez une organisation standardisée
- ✅ **Descriptions personnalisées** pour ajouter du contexte spécifique à chaque classe
- ✅ **Mode brouillon** (visible = false) pour préparer du contenu sans le publier

#### Performance

- 🔄 **Synchronisez régulièrement** (recommandé : une fois par semaine)
- 📦 **Ne synchronisez que les cours actifs** (archivez les anciens cours dans Google Classroom)
- 🎯 **Limitez le nombre de pièces jointes** par matériel (< 10 recommandé)

## Pour les élèves

### 1. Accéder au matériel pédagogique

1. Connectez-vous à UbuMaths
2. Naviguez vers **Tableau de bord élève** → **Matériel pédagogique**
3. Consultez les documents partagés par vos enseignants

### 2. Filtrer les documents

Utilisez les filtres pour trouver rapidement ce que vous cherchez :

- **Par classe** - Affichez uniquement les documents d'une classe
- **Par catégorie** - Filtrez par type (Cours, Exercices, etc.)
- **Par rubrique** - Filtrez par rubrique Google (si utilisée)

**Astuce** : Combinez les filtres pour des recherches précises (ex: "Cours" dans "Mathématiques 3e").

### 3. Consulter un document

Chaque carte de matériel affiche :

- 📄 **Titre du document**
- 🏫 **Classe concernée**
- 👨‍🏫 **Enseignant qui a partagé**
- 📅 **Date de partage**
- 📝 **Description** (originale ou personnalisée par l'enseignant)
- 📎 **Pièces jointes** (fichiers, vidéos, liens)

#### Types de pièces jointes

| Icône | Type                 | Action                       |
| ----- | -------------------- | ---------------------------- |
| 📄    | Fichier Google Drive | Ouvrir dans Drive            |
| 🎥    | Vidéo YouTube        | Regarder sur YouTube         |
| 🔗    | Lien externe         | Ouvrir dans un nouvel onglet |
| 📋    | Formulaire Google    | Remplir le formulaire        |

**Cliquez** sur une pièce jointe pour l'ouvrir dans un nouvel onglet.

### 4. Navigation

- **Pagination** : Utilisez les boutons < et > pour naviguer entre les pages (20 documents par page)
- **Retour en haut** : Cliquez sur le titre "Matériel pédagogique" pour revenir en haut
- **Google Classroom** : Bouton "Ouvrir dans Google Classroom" pour voir le matériel original

## Organisation des matériaux

### Logique d'affichage

Les matériaux sont regroupés dans l'ordre de priorité suivant :

1. **Catégorie UbuMaths** (si assignée)
2. **Rubrique Google** (si assignée et pas de catégorie)
3. **Non classé** (si ni catégorie ni rubrique)

**Exemple** :

```
📚 Cours (3)
  - Introduction aux fractions
  - Propriétés des nombres décimaux
  - Géométrie dans l'espace

✏️ Exercices (5)
  - Exercices fractions niveau 1
  - Exercices fractions niveau 2
  - ...

📐 Pythagore (Rubrique Google) (2)
  - Théorème de Pythagore
  - Applications pratiques

Non classé (1)
  - Ressources complémentaires
```

### Dénormalisation stratégique

**Pour les développeurs** : Les champs `course_name` et `teacher_name` sont dénormalisés dans la table `shared_materials` pour :

- Éviter les dépendances circulaires RLS
- Améliorer les performances (1 requête au lieu de 3)
- Réduire la complexité du code

Les déclencheurs automatiques maintiennent la cohérence :

- Insertion : Auto-remplissage des noms
- Mise à jour cours : Propagation aux matériaux partagés
- Mise à jour enseignant : Propagation aux matériaux partagés

## Sécurité et confidentialité

### Contrôle d'accès

- ✅ **Enseignants** : Accès complet à leurs propres matériaux et partages
- ✅ **Élèves** : Accès uniquement aux matériaux visibles partagés avec leurs classes
- ✅ **Admins** : Accès lecture seule pour support

### Row Level Security (RLS)

Toutes les tables utilisent des politiques RLS strictes :

- **google_classroom_materials** : Teachers can view/edit their own
- **shared_materials** : Teachers can share with their classes only
- **material_attachments** : Students can view attachments of shared materials
- **topics** : Accessible if course is accessible

### Chiffrement

**Tokens OAuth** :

- Chiffrement AES-256-GCM côté application
- Clé stockée dans variable d'environnement (jamais en base)
- Déchiffrement uniquement côté serveur

## Dépannage

### Problème : Le matériel ne s'affiche pas

**Solutions** :

1. **Vérifiez la visibilité** - L'enseignant a peut-être désactivé la visibilité
2. **Vérifiez la classe** - Le matériel est peut-être partagé avec une autre classe
3. **Actualisez la page** - Utilisez F5 ou Ctrl+R
4. **Vérifiez votre appartenance** - Êtes-vous bien dans la classe ?

### Problème : La synchronisation échoue

**Solutions** :

1. **Reconnectez votre compte Google** - Les tokens ont peut-être expiré
2. **Vérifiez les permissions** - Google Classroom doit autoriser l'accès en lecture
3. **Contactez votre administrateur** - En cas d'erreur persistante

### Problème : Les pièces jointes ne s'ouvrent pas

**Solutions** :

1. **Vérifiez votre connexion Google** - Vous devez être connecté à Google
2. **Vérifiez les autorisations** - Le fichier Drive est peut-être privé
3. **Essayez un autre navigateur** - Problème de cookies/cache possible

## Foire aux questions (FAQ)

### Quelle est la différence entre "matériel pédagogique" et "devoirs" ?

- **Matériel pédagogique** (CourseWorkMaterials) : Documents **non-évalués** pour consultation (vidéos, PDFs, liens)
- **Devoirs** (CourseWork) : Travaux **à rendre et à évaluer** avec notes

UbuMaths synchronise les deux séparément. Cette page concerne uniquement le matériel pédagogique.

### Puis-je partager du matériel avec seulement certains élèves ?

**Non, pas actuellement**. Le partage se fait au niveau de la classe entière. Tous les élèves de la classe voient le même matériel.

**Alternative** : Créez des classes séparées pour des groupes spécifiques.

### Les matériaux sont-ils stockés dans UbuMaths ?

**Non**. UbuMaths stocke uniquement les **métadonnées** (titre, description, liens). Les fichiers restent dans Google Drive/Google Classroom.

**Avantages** :

- Pas de duplication de données
- Mises à jour automatiques si vous modifiez le fichier dans Google
- Pas de limite de stockage UbuMaths

### Que se passe-t-il si je supprime un matériel dans Google Classroom ?

Lors de la prochaine synchronisation :

1. Le matériel est marqué comme `state = 'DELETED'` dans UbuMaths
2. Il disparaît automatiquement de l'interface élève
3. Les partages existants sont conservés (pour historique)

**Pour le supprimer définitivement** : Supprimez les partages manuellement dans UbuMaths.

### Combien de classes puis-je partager simultanément ?

**Illimité**. Vous pouvez partager un matériel avec toutes vos classes en une seule opération.

### Les élèves peuvent-ils télécharger les fichiers ?

**Cela dépend** des permissions Google Drive du fichier original :

- Si le fichier est en **lecture seule** : Consultation uniquement
- Si le fichier est **téléchargeable** : Les élèves peuvent télécharger

**UbuMaths n'impose aucune restriction** - il respecte les permissions Google.

## Limites connues

### Limitations actuelles

- ⚠️ **Pas de partage individuel** - Uniquement au niveau de la classe
- ⚠️ **Pas de sync temps réel** - Synchronisation manuelle requise
- ⚠️ **Matériaux publiés uniquement** - Les brouillons Google ne sont pas synchronisés
- ⚠️ **Pas de modification inline** - Les changements doivent être faits dans Google Classroom
