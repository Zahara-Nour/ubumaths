# 📊 Workflow Enseignant - Évaluations

Guide du workflow enseignant pour créer et gérer des évaluations.

**Status** : 📝 Documentation en cours

---

## 🎯 Vue d'ensemble

Ce document détaille le parcours complet d'un enseignant pour créer, assigner, et corriger des évaluations.

---

## 📝 Créer une évaluation

### 1. Accéder à la banque de questions

```
Dashboard → Enseignant → Questions
```

### 2. Sélectionner les questions

- Filtrer par catégorie, difficulté, type
- Prévisualiser chaque question
- Ajouter à l'évaluation

### 3. Configurer l'évaluation

- **Titre** : Nom de l'évaluation
- **Description** : Instructions pour les élèves
- **Date limite** : Optionnelle
- **Paramètres** :
  - Afficher score immédiatement ou non
  - Permettre plusieurs tentatives
  - Mélanger l'ordre des questions

### 4. Assigner aux classes

- Sélectionner une ou plusieurs classes
- Option : Assigner à certains élèves uniquement

---

## 📊 Suivi des soumissions

### Dashboard évaluations

```
Dashboard → Enseignant → Évaluations → [Évaluation] → Résultats
```

Voir :
- Nombre de soumissions / nombre d'élèves
- Statut par élève (Complété / En cours / Pas commencé)
- Scores moyens
- Temps moyen de complétion

### Alertes

Notification quand :
- Un élève soumet son évaluation
- Date limite approche
- Anomalie détectée (temps très court/long)

---

## ✍️ Correction

### Auto-correction

Questions auto-corrigées :
- Choix multiples
- Vrai/Faux
- Réponse courte (exacte)

### Correction manuelle

Questions nécessitant correction :
- Réponse longue
- Upload de fichiers
- Questions ouvertes

**Interface de correction** :
1. Voir la réponse élève
2. Attribuer points
3. Ajouter commentaire
4. Passer à l'élève suivant

---

## 📈 Analyse des résultats

### Statistiques par question

- Taux de réussite
- Temps moyen par question
- Questions les plus difficiles

### Statistiques par élève

- Score global
- Performance par type de question
- Progression dans le temps

---

## 🔄 Actions possibles

- **Dupliquer** une évaluation
- **Archiver** une évaluation passée
- **Exporter** résultats en CSV
- **Modifier** évaluation (avant soumissions)
- **Supprimer** évaluation (confirmation requise)

---

## 💡 Best Practices

### Conception

- Varier les types de questions
- Équilibrer difficulté
- Prévoir temps suffisant
- Tester soi-même avant assignation

### Suivi

- Corriger rapidement (feedback rapide = meilleur apprentissage)
- Ajouter commentaires constructifs
- Identifier patterns d'erreurs communes
- Ajuster enseignement selon résultats
