# 📝 Workflow Élève - Évaluations

Guide du workflow élève pour passer des évaluations.

**Status** : 📝 Documentation en cours

---

## 🎯 Vue d'ensemble

Ce document détaille le parcours d'un élève pour consulter, passer, et voir les résultats d'une évaluation.

---

## 📋 Voir les évaluations assignées

### Dashboard élève

```
Dashboard → Élève → Évaluations
```

Voir :

- Évaluations à faire (avec date limite)
- Évaluations en cours
- Évaluations complétées

### Informations disponibles

- Titre et description
- Nombre de questions
- Temps estimé
- Date limite
- Nombre de tentatives autorisées

---

## ✏️ Passer une évaluation

### Démarrer

1. Cliquer sur "Commencer l'évaluation"
2. Lire les instructions
3. Confirmer le début (timer démarre)

### Interface de passage

- **Navigation** : Passer d'une question à l'autre
- **Progression** : Barre de progression (X/Y questions)
- **Brouillon** : Réponses sauvegardées automatiquement
- **Marquage** : Marquer questions à revoir
- **Timer** : (si limite de temps)

### Types de questions

- **Choix multiples** : Sélectionner une ou plusieurs réponses
- **Vrai/Faux** : Cocher vrai ou faux
- **Réponse courte** : Saisir texte/nombre
- **Réponse longue** : Rédiger réponse développée
- **Upload** : Télécharger fichier (photo, PDF)

### Soumission

1. Vérifier toutes les réponses
2. Cliquer "Soumettre l'évaluation"
3. Confirmer soumission (irréversible)

---

## 📊 Voir les résultats

### Score immédiat (si activé)

Affichage direct après soumission :

- Score total (/20 ou /100)
- Questions correctes/incorrectes
- Corrections (si autorisé par enseignant)

### Score différé

Attendre correction de l'enseignant :

- Notification quand corrigé
- Accès aux résultats dans Dashboard

### Détails des résultats

- Score par question
- Réponses données vs réponses correctes
- Commentaires de l'enseignant
- Temps passé

---

## 🔄 Tentatives multiples

Si autorisé par l'enseignant :

1. Voir score première tentative
2. Cliquer "Nouvelle tentative"
3. Questions possiblement mélangées
4. Meilleur score conservé

---

## 💡 Conseils

### Avant de commencer

- Lire attentivement les instructions
- Vérifier temps disponible
- Préparer environnement calme
- Avoir papier/calculatrice si nécessaire

### Pendant l'évaluation

- Gérer son temps (ne pas rester bloqué)
- Marquer questions incertaines
- Relire avant soumission
- Vérifier calculs

### Après l'évaluation

- Analyser erreurs
- Comprendre corrections
- Revoir notions non maîtrisées
- Demander aide si nécessaire

---

## ❓ Problèmes courants

### Connexion perdue

- Réponses sauvegardées automatiquement
- Reconnecter et continuer
- Contacter enseignant si problème persiste

### Timer écoulé

- Soumission automatique
- Réponses actuelles enregistrées

### Question bloquée

- Passer à suivante et revenir
- Marquer pour y revenir
- Ne pas perdre trop de temps
