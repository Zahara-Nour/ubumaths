### A. Migration Script Test Mode Support

   - Set `created_by` to null

**Usage**:
```bash

pnpm tsx scripts/migrate-questions-phase1.ts --test            # Test actual migration
```

### B. State Manager Type Flexibility

**File**: `src/lib/server/migration/state-manager.ts`

**Changes**:
1. Modified `recordQuestionProcessed()` to accept `any` type instead of `QuestionToMigrate`
2. Updated `generateQuestionHash()` to handle both `QuestionToMigrate` and `QuestionBase` formats
3. Updated `generateDescription()` to handle both formats:
   - Falls back to `description` or `enounces[0]` if `statement` is missing
   - Handles missing `type` field

**Reason**: The old questions use `QuestionBase` format which has different field names than `QuestionToMigrate`.

### C. Syntax Converter Regex Fix

**File**: `src/lib/migration/syntax-converter.ts`

**Change**: Fixed invalid regex pattern on line 325
```typescript
// Before (invalid - unterminated group):
const pattern4 = /\[(_([^]*?)_]/g;

// After (valid - escaped parenthesis):
const pattern4 = /\[\(_([^]*?)_]/g;
```

**Impact**: Prevented runtime `SyntaxError: Invalid regular expression` errors.

### D. Question Transformer ID Field

**File**: `src/lib/migration/question-transformer.ts`

**Change**: Removed `id: ''` from template creation (line 742)
```typescript
// Before:
const template: QuestionTemplate = {
  id: '', // Will be assigned during import
  type: questionType,
  ...
};

// After:
const template: QuestionTemplate = {
  // id field omitted - will be auto-generated by database
  type: questionType,
  ...
};
```

**Reason**: Database expects UUID to be auto-generated, not empty string.

### Critical Fixes Applied

1. **Regex Syntax Error** (syntax-converter.ts)
   - **Problem**: Invalid regex pattern crashed the module
   - **Fix**: Escaped parenthesis in pattern
   - **Impact**: Prevented all migrations from running

2. **UUID Empty String** (question-transformer.ts, migrate-questions-phase1.ts)
   - **Problem**: Template had `id: ""` which database rejected
   - **Fix**: Removed id field, let database auto-generate
   - **Impact**: All database inserts were failing

3. **Type Mismatch** (state-manager.ts)
   - **Problem**: Expected QuestionToMigrate but received QuestionBase
   - **Fix**: Made generateHash/generateDescription handle both formats
   - **Impact**: State manager couldn't process old questions
