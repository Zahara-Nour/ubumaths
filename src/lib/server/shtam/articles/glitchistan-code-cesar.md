C'est le signataire de ces lignes qui a intercepté la lettre, glissée dans la sacoche d'un messager russe. Le texte était incompréhensible : « DWWDTXH D O'DXEH ». Le Capitaine Bordure a voulu la brûler, « par précaution ». J'ai demandé à la garder un après-midi.

J'ai essayé une idée simple : remplacer chaque lettre par celle qui la précède de trois rangs dans l'alphabet. Le D devient A, le W devient T, le X devient U. Le message est apparu : « ATTAQUE À L'AUBE ». La Garde a été mise en alerte. L'attaque n'a pas eu lieu, le Czar ayant appris que sa lettre avait été lue.

Le palais de Moscou a réagi en renforçant immédiatement la sécurité de ses messages. Selon nos sources, les lettres du Czar sont désormais décalées de **quatre** rangs. Il m'a fallu un quart d'heure de plus pour lire la suivante. Elle disait : « ILS ONT DÉCHIFFRÉ. ON PASSE À 4. »

Le Czar envisage d'aller jusqu'à 25. Les cryptographes du Royaume lui ont fait savoir, par courtoisie, qu'à 26 on retombe sur le message de départ.

## Le vrai du faux

C'est le **chiffre de César** : chaque lettre est remplacée par celle qui se trouve un nombre fixe de rangs plus loin dans l'alphabet. Jules César l'utilisait, dit-on, avec un décalage de 3.

- Avec un décalage de 3, A devient D, B devient E, et UBU devient XEX. Pour déchiffrer, on décale dans l'autre sens.
- Ce code est **très faible** : il n'y a que **25 décalages** possibles. Il suffit de les essayer tous. On peut aussi repérer la lettre la plus fréquente du message : en français, c'est souvent le **E**.
- Les chiffrements modernes, qui protègent nos messages et nos paiements, reposent sur des mathématiques beaucoup plus solides, notamment sur les **nombres premiers**.
